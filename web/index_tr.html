Idle Ara Animasyonlari

Yuzler sekmesindeki aktif yuz ana/default yuzdur. Buradaki animasyonlar onun arasina kisa, rastgele ara bakis/tepki gibi girer.

Idle ara animasyonu olacak yuzleri checkbox ile sec. Secilenlerin tur/saniye ayarlarini asagidan duzenleyebilirsin.

Ara idle bekleme:

Default yuz oynarken bu aralik dolunca listedeki ara idle animasyonlarindan biri rastgele girer. Random Event, ara idle oynarken baslamaz.

Opening Event

Cihaz acilirken secilen yuzlerden biri rastgele oynar. Bos birakirsan animasyonlu "Hello there!" gosterilir.

Random Event

Default/aktif yuz oynarken arada bir secilen yuzlerden biri rastgele oynatilir. Idle ara animasyon ile ayni kavram degildir: idle ara surekli dongusel; random event ise nadir, "tek atislik" surprise. Idle ara animasyon oynarken random event tetiklenmez. Asagidaki min-max aralik = bir random sonrasi diger random'a kadar gecen sure.

Uyku / Uyanma Animasyonlari

Uykuya girerken ve uyanirken oynatilacak animasyon havuzlarini buradan sec. Sistem, secilenlerden birini rastgele oynatir. Animasyon kendi toplam suresi kadar oynar; ayrica ms belirlenmez.

Uykuya giris animasyonlari

Secilenlerden biri uykuya girerken rastgele oynar. Bos birakirsan direkt kapanir.

Uyanma animasyonlari

Secilenlerden biri dokununca rastgele oynar. Bos birakirsan direkt default yuze doner.

Dokunma Kalibrasyonu

Bu ayarlar TTP223 dokunma sensorunun dokunusu nasil yorumlayacagini belirler. Varsayilan degerler: Sevilme 200 ms, Cok sevilme 3000 ms, Debounce 35 ms.

Sevilme ms: Parmağın sensore bu sureden uzun degirse normal sevilme/petting sayilir. Dusurursen daha kolay tetiklenir, yukseltirsen kisa dokunuslari daha az yakalar.
Cok sevilme ms: Parmağın sensorde bu kadar kalirsa deep petting/cok sevilme animasyonu baslar. Ornek: 3000 = 3 saniye.
Debounce ms: TTP223'un titresim/parazit yuzunden tek dokunusu birden fazla saymasini engeller. Cift sayiyorsa 50-70 ms deneyebilirsin.
